# FK Grafik-Designer

Update-Quelle für das WordPress/WooCommerce-Plugin **FK Grafik-Designer** – ein Produkt von [feinklick.ch](https://feinklick.ch).

- `info.json` – aktuelle Version, Paket-URL (GitHub-Release) und Ed25519-Signatur
- [Releases](https://github.com/divanasi/fk-grafik-designer/releases) – signierte Plugin-ZIPs

Das Plugin installiert Updates nur, wenn die Signatur zum öffentlichen Schlüssel im Plugin passt (`o5ImpAli82e1Kf4djoMEGcycKtCj/AzYQVnaKqoxDAk=`). Signiert wird «fk-grafik-designer|Version|SHA-384 der ZIP».
